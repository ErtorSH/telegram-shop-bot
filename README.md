🕶️ ربات فروشگاهی تلگرام
ربات فروشگاه آنلاین با پایتون — ثبت‌نام، سبد محصولات، سفارش با پرداخت کارت‌به‌کارت و پنل مدیریت کامل

✨ امکانات
👤 ثبت‌نام کاربران با اعتبارسنجی کد پستی
🕶️ لیست محصولات با گالری تصاویر
🛍 ثبت سفارش با ارسال فیش واریزی
✅ تأیید/رد سفارش توسط مدیر
📦 پیگیری سفارش با کد رهگیری پستی
🛒 سابقه خریدها با مجموع مبالغ
👨‍💼 پنل مدیریت (افزودن/حذف محصول، تغییر موجودی، مدیریت سفارش‌ها)
🔔 اطلاع‌رسانی خودکار وضعیت سفارش به مشتری
🛠 تکنولوژی‌ها
Python 3
pyTelegramBotAPI (TeleBot)
SQLite
python-dotenv
🚀 اجرا
نصب پیش‌نیازها:pip install -r requirements.txt
ساخت فایل .env:BOT_TOKEN=توکن-ربات-از-BotFatherADMIN_ID=آیدی-عددی-ادمینCARD_NUMBER=شماره-کارتCARD_OWNER=نام-صاحب-کارت
اجرا:python main.py
☁️ دیپلوی
قابلیت دیپلوی روی Render / Railway / هر هاست پایتونی با تنظیم Environment Variables و Start Command: python main.py
